## Runtime delivery

Delivery is intentionally pending the release orchestrator. The real workflow
uses `~/.local/bin/codex`, `~/.local/bin/codex-tui`, and the immutable release
selected by `~/.local/lib/codex/current`, plus installed sound/transcription
helpers under the Codex home. This integration task is prohibited from updating
those locations. No fresh build was produced because dependency access failed.
The orchestrator must inventory discoverable copies, install the validated
release and matching helpers, prove their identity, and exercise the actual
launch path before treating the release as delivered.
